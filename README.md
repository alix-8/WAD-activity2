# Real Estate Management System - Laravel Integration

## Description of the System
The Real Estate Management System is a web-A real estate system that lists the agents of a brokerage firm and displays the properties handled by each agent, including the amenities and addresses of the properties.

---

# Lists of Implemented Features

# Core Functions
- Supports complete CRUD operations
- Role-based access control using login authentication
- Ownership and permission enforcement
- Proper database relationship implementation
  
# Role Authorization
- Admin
- Manage agents
- Add and edit properties
- Manage property details, amenities, and addresses
  
# User
- View agents
- View properties and property details only
